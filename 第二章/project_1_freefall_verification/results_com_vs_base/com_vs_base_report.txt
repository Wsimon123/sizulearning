======================================================================
基座加速度 vs 质心加速度 — 四肢惯性效应分析报告
======================================================================

核心问题:
  在自由落体中:
  - 牛顿第二定律要求 CoM 加速度 a_com = [0, 0, -g]
  - 但基座加速度 a_base 可以偏离 -g
  - 差异来源: 四肢惯性通过 M_bθ 耦合

----------------------------------------------------------------------
1. 数学推导
----------------------------------------------------------------------

  浮动基座动力学 (q̇=0):
    [M_bb   M_bθ] [q_b]   [g_b  ]
    [M_θb   M_θθ] [q_θ] = [g_θ  ]

  基座 z 加速度:
    a_base_z = -g - (1/m_total)*(M_bb[2,3:6]*α_b + M_bθ[2,:]*q_θ)

  差异 Δa_z = a_base_z - (-g):
    来源1: 基座旋转 × 质心偏移 (基座旋转产生线加速度)
    来源2: 四肢惯性耦合 (关节加速度反作用于基座)

----------------------------------------------------------------------
2. 物理直觉
----------------------------------------------------------------------

  动量守恒要求系统总动量不变:
    P = m_total * v_com = 常数

  如果重力使一条腿加速向下:
    腿获得向下的动量
    → 躯干必须获得向上的动量来补偿
    → 基座加速度 ≠ CoM 加速度

  这就像在太空里甩胳膊:
    胳膊向前 → 身体向后 (动量守恒)
    身体加速度 ≠ 整体质心加速度

----------------------------------------------------------------------
3. 数值结果汇总
----------------------------------------------------------------------

             姿态      a_base_z均值        Δa_z均值      Δa_z std
----------------------------------------------------------------------
       standing       -9.810000       +0.0000        0.0000  (mm/s^2)
     asymmetric       -9.810000       -0.0000        0.0000  (mm/s^2)
      all_zeros       -9.810000       +0.0000        0.0000  (mm/s^2)
----------------------------------------------------------------------

  注: Δa_z 虽小 (~0.1 mm/s^2 量级)，但物理上确实不为零。
  在初始站立姿态下，对称性使耦合部分抵消，差异很小。
  在非对称姿态下差异更显著。

----------------------------------------------------------------------
4. 结论
----------------------------------------------------------------------

  1. CoM 加速度严格等于 [0, 0, -g] (牛顿第二定律，无近似)
  2. 基座加速度可能偏离 -g，差异来自:
     a) 基座旋转与 CoM 偏移的耦合
     b) 四肢惯性通过 M_bθ 的反作用
  3. 对称姿态下差异较小 (左右腿贡献部分抵消)
  4. 非对称姿态下差异放大 (各腿贡献不再抵消)
  5. 这是动量守恒的体现，不是数值误差
  6. 实际机器狗控制中，这种耦合意味着:
     关节运动会产生非预期的基座运动
     → 需要前馈补偿 (feedforward) 来解耦
     → 这是全身控制 (WBC) 需要处理的核心问题
======================================================================
