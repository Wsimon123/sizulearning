======================================================================
关节阻尼/摩擦对自由落体结果的影响
======================================================================

1. 理论结论
----------------------------------------------------------------------
  阻尼力的本质: 关节处的内力对 (父体 - 子体)
  → 内力对合力为零 → 不影响 CoM 加速度
  → a_com 恒为 -g, 与阻尼大小无关

  但阻尼改变了关节运动:
  → 阻尼力 = -d * q_dot_joint
  → 改变 q_ddot_joint
  → 通过 M_bθ 耦合影响基座加速度
  → a_base 依赖于阻尼水平

2. 数值结果
----------------------------------------------------------------------
                阻尼水平     CoM a_z     Δa_z 均值     Δa_z 峰值     Δa_z 终点
----------------------------------------------------------------------
           d=0 (无阻尼)   -9.810360     -163.10      723.24      -18.57  (mm/s^2)
          d=0.1 (轻微)   -9.810804     -166.13      493.89      -15.96  (mm/s^2)
          d=0.5 (适中)   -9.810693     -146.03     1765.53       -1.20  (mm/s^2)
          d=1.0 (标准)   -9.810627     -142.27     3199.38       -1.83  (mm/s^2)
          d=5.0 (重度)   -9.810398     -126.42    10616.28       -1.83  (mm/s^2)
----------------------------------------------------------------------

3. 关键发现
----------------------------------------------------------------------
  a) CoM 加速度始终为 -9.81 m/s^2 (误差 < 0.01%), 与阻尼无关
     → 阻尼是内力, 不改变系统总动量演化

  b) 阻尼增大 → 关节速度衰减更快 → 四肢惯性效应衰减更快
     → Δa_z 终值更小 (阻尼耗散了关节动能)

  c) 阻尼在初始时刻 (t=0) 对 a_base 有瞬时影响:
     阻尼力 = -d * qvel(0) → 产生关节力矩 → M_bθ 传到基座
     → 即使 q_ddot 还没变, 阻尼力已经通过 qfrc_bias 改变了方程

  d) 从能量视角:
     重力势能 → 整体动能 + 关节动能
     阻尼 → 关节动能 → 热能 (耗散)
     最终状态: 阻尼越大, 残余关节运动越小, a_base 越接近 a_com

4. 实际意义
----------------------------------------------------------------------
  真实机器狗的关节阻尼 ~0.1-1.0 N*m*s/rad
  - 阻尼会自然衰减关节振荡 → 四肢惯性效应是瞬态现象
  - 但在主动运动时 (tau != 0), 关节持续驱动 → 效应持续存在
  - 控制器需要补偿的是主动驱动产生的 M_bθ 耦合, 而非阻尼
  - 高阻尼使仿真更稳定但可能掩盖真实的动力学耦合
======================================================================
