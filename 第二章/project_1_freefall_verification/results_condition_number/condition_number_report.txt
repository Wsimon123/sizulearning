======================================================================
条件数过大 (≈1200) 的物理含义
======================================================================

1. 动力学刚度极度不均匀
   基座平动: 有效惯性 = 15.0 kg (整个机器人一起动)
   膝关节:   有效惯性 ≈ 0.0124 kg·m²
   差距约 1204 倍

2. 逆动力学对误差敏感
   q̈ = M^{-1} * (tau - h)
   M 条件数大 → M^{-1} 将小的 tau 误差放大到关节加速度
   例如: 力矩 1% 误差 → 膝加速度 ~10% 偏差

3. 接触求解数值病态
   接触力 lambda 的计算涉及 M^{-1} * J^T
   条件数大 → 接触力求解精度下降 → 可能抖动或穿透

4. 多速率系统
   基座运动带宽 ~10 Hz, 关节运动带宽 ~350 Hz
   仿真步长必须解析最快动态 → dt <= 0.5 ms (Nyquist)
   实际 MuJoCo 使用隐式积分器可以适当放宽

5. 控制挑战
   统一控制器难以兼顾所有时间尺度
   解决方案: 频带分离 (task-space + joint-space 分级控制)

6. 本质
   这不是 bug, 而是浮动基座系统的固有特性
   总质量 >> 单关节惯量 → 所有腿式机器人的共性
