角动量守恒验证 — 汇总报告
======================================================================

物理原理:
  自由落体中无外力矩 (tau=0, 无接触)
  → dL_COM/dt = Σ τ_ext = 0
  → L_COM = 常数
  初始条件: 所有速度为零 → L_COM(0) = 0
  → 任意时刻 L_COM(t) = 0

角动量公式 (每体贡献):
  L = Σ [ r_i × (m_i*v_i) + R_i*diag(I_body_i)*R_i^T * ω_i ]
       ├── 轨道角动量 ──┤  ├────── 自旋角动量 ──────┤

======================================================================
重要区分: L_origin vs L_COM
======================================================================

  L_origin = 关于世界原点的角动量
  L_COM    = 关于系统质心 (COM) 的角动量

  关系: L_origin = r_COM × M_total * v_COM + L_COM

  自由落体中:
  - r_COM 和 v_COM 都在变化 (质心在运动)
  - 因此 L_origin 必然变化 (并非守恒量!)
  - L_COM 才是真正的守恒量

  ★ 验证目标: L_COM ≈ 0 且恒定 ★

======================================================================
深入分析
======================================================================

1. 为什么 L_origin 不为零?

   L_origin 关于原点, 原点不是系统的特殊点。
   系统质心下坠时, r_COM 和 v_COM 都在变化:
     L_origin = r_COM × M_total*v_COM + L_COM
              = (变化的量)           + (守恒的 0)

   例如 standing 姿态:
     max|L_origin| = 0.136  (看似很大)
     max|L_COM|    = 2.9e-16 (实际守恒!)
     L_origin 的变化 ≈ r_COM_变化 × M*v_COM ≈ 0.4 × 10 × 0.981 × 0.1 ≈ 0.4

2. 为什么 L_COM 严格守恒?

   外力矩 = 0 → dL_COM/dt = 0 (刚体动力学基本定理)
   MuJoCo 的半隐式 Euler 是辛积分器, 精确保持此守恒律
   即使在非对称姿态下, 关节被动运动也不会产生净角动量

3. 半隐式 Euler 的辛性质

   辛方法 (symplectic integrator) 保持相空间结构:
   - 精确守恒: 线性动量, 角动量 (无外力时)
   - 近似守恒: 能量 (有 O(dt) 振荡, 但无长期漂移)
   因此角动量在机器精度内严格守恒, 与步长无关

======================================================================
结论
======================================================================

  1. 关于 COM 的角动量 L_COM 在所有姿态下严格守恒
     (max|L_COM| ~ 10^-16, 机器精度极限)

  2. 关于原点的角动量 L_origin 并不守恒, 这是预期行为
     (因为质心在运动: L_origin = r_COM × M*v_COM + L_COM)

  3. L_COM 守恒与步长无关 (0.1ms~10ms)
     — 半隐式 Euler 的辛性质保证

  4. L_COM 守恒与姿态无关 (对称/非对称/蹲伏/伸展)
     — 关节内力不能产生净角动量 (牛顿第三定律)

  5. 验证了 MuJoCo 浮动基座动力学正确保持了角动量守恒定律
