分析
======================================================================

1. 加速度误差 (a_z 相对误差)
   - 所有步长下加速度误差均为 0.0000%
   - 原因: 纯自由落体中重力是恒力 (F = m·g = 常数)
   - 半隐式 Euler 对恒力是精确的: a_t = F/m = g, 与 dt 无关
   - 中心差分 (v_{k+1} - v_{k-1})/(2dt) 完美恢复恒加速度

2. 速度误差
   - 所有步长下速度误差均为 0.00000000 m/s
   - 原因: 加速度恒定的情况下, v_k = v_0 + k·a·dt 是精确线性的
   - 中心差分严格恢复 −9.81 m/s²

3. 位置误差 (真正的积分误差) — 为什么步长越长, 位置误差越大?

   【实测数据】
   - 位置误差随步长线性增长:
       0.1ms → 0.00004905 m  (≈ 0.05 mm)
       1ms   → 0.00049050 m  (≈ 0.5 mm)
       5ms   → 0.00245250 m  (≈ 2.5 mm)
       10ms  → 0.00490500 m  (≈ 4.9 mm)
   - 步长放大 100 倍 (0.1ms → 10ms), 误差也放大 100 倍 ✓

   【理论推导: 半隐式 Euler 的局部截断误差】

   半隐式 Euler 更新公式 (MuJoCo 使用的积分器):
       步骤1:  v_{k+1} = v_k + a·dt           (用当前加速度更新速度)
       步骤2:  z_{k+1} = z_k + v_{k+1}·dt     (用新速度更新位置)

   对自由落体, a = -g (常数):

   (a) 速度序列是严格线性的:
       v_k = v_0 - k·g·dt

   (b) 位置是每一步位移的累加:
       z_n = z_0 + Σ_{k=0}^{n-1} v_{k+1}·dt
           = z_0 + Σ_{k=0}^{n-1} [v_0 - (k+1)·g·dt]·dt
           = z_0 + v_0·n·dt - g·dt²·Σ_{k=0}^{n-1}(k+1)
           = z_0 + v_0·t - g·dt²·n(n+1)/2          (n = t/dt)
           = z_0 + v_0·t - ½·g·t·(t + dt)
           = z_0 + v_0·t - ½·g·t² - ½·g·t·dt       ← 数值解

   (c) 精确解 (连续物理):
       z_exact(t) = z_0 + v_0·t - ½·g·t²

   (d) 两式相减, 得到位置误差:
       err(t) = z_numerical - z_exact = -½·g·t·dt
       ┌─────────────────────────────────────────────────────┐
       │  pos_err = ½·g·t·dt   →   误差 ∝ dt (正比于步长)   │
       └─────────────────────────────────────────────────────┘

   (e) 代入验证 (t = 0.1s, g = 9.81):
       dt = 0.0001  →  err = ½ × 9.81 × 0.1 × 0.0001 = 0.00004905 m  ✓
       dt = 0.001   →  err = ½ × 9.81 × 0.1 × 0.001  = 0.00049050 m  ✓
       dt = 0.005   →  err = ½ × 9.81 × 0.1 × 0.005  = 0.00245250 m  ✓
       dt = 0.01    →  err = ½ × 9.81 × 0.1 × 0.01   = 0.00490500 m  ✓
       理论值与测量值完全一致!

   【为什么加速度反而精确?】
   从 v_k = v_0 - k·g·dt 可知速度是严格的线性序列。
   中心差分对线性函数是精确的 (这是数值分析的基本性质):
       (v_{k+1} - v_{k-1}) / 2dt
     = [(-(k+1)g·dt) - (-(k-1)g·dt)] / 2dt
     = [-kg·dt - g·dt + kg·dt - g·dt] / 2dt
     = -2g·dt / 2dt
     = -g
   所以加速度误差永远为 0, 与 dt 无关。这不是巧合——半隐式 Euler
   是一阶辛方法 (symplectic integrator), 对恒力系统速度是精确的。

   【直观理解】
   每一步积分相当于用矩形条近似抛物线下的面积。dt 越大,
   每个矩形条的高度偏差越大, 累积的面积误差就越大:
       dt=0.1ms (1000步):  ████████████████████████  几乎完美贴合曲线
       dt=10ms  (10步):    ████░░░░████░░░░████░░░░  每一步都明显偏离

4. 物理意义
   - 纯自由落体场景下, 加速度不受步长影响
   - 在实际应用中 (有关节力矩、接触力、地面反力), 由于力随状态变化,
     加速度误差会随步长增大而显著增加
   - 本实验验证了 MuJoCo 半隐式 Euler 积分器对恒力系统的精确性

======================================================================
结论
======================================================================

  - 自由落体中加速度误差对所有步长均为 0% — 恒力系统的特例
  - 位置积分误差与步长成正比 (O(dt)), 与理论预测一致
  - 0.1ms~1ms 步长下位置误差 < 0.5mm, 适合高精度离线仿真
  - 5ms 步长是实时 MPC 控制的常用选择, 位置误差约 2.5mm (可接受)
  - 10ms 步长位置误差约 5mm, 需评估是否满足控制精度要求
  - 注意: 本实验无接触/关节力矩, 实际仿真中误差会更大
======================================================================
一句话总结：步长越大，每一步积分时用"当前速度 × dt"近似位移的误差就越大，这些误差线性累积，最终 err ∝ dt。
